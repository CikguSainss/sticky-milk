STICKY MILK — POLISHED WEBSITE
===============================

This version keeps the original Sticky Milk content and adds:
- Cleaner modern design
- Better mobile layout
- Improved flavour cards
- Location section for TVETMARA Lumut
- Embedded Google Maps
- Google Maps directions button
- Improved order UI
- WhatsApp order message

IMPORTANT:
Open script.js and replace:
const WHATSAPP_NUMBER = "601XXXXXXXXX";
with the real Malaysia WhatsApp number, without + or spaces.

Example:
const WHATSAPP_NUMBER = "60123456789";

To publish on GitHub Pages:
1. Extract this ZIP.
2. Upload/replace index.html, style.css, script.js and images/ in your sticky-milk repository.
3. Keep index.html at the repository root.
4. GitHub Pages will update after the commit/deployment finishes.
