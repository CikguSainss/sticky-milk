STICKY MILK WEBSITE
====================

Files:
- index.html
- style.css
- script.js
- images/logo.png
- images/product-poster.png

IMPORTANT:
Open script.js and replace:
const WHATSAPP_NUMBER = "601XXXXXXXXX";
with your actual Malaysia WhatsApp number, without + or spaces.

Example:
const WHATSAPP_NUMBER = "60123456789";

To preview:
1. Keep all files/folders together.
2. Double-click index.html.
3. The website will open in your browser.

To publish online later, this folder can be uploaded to a static hosting service.
